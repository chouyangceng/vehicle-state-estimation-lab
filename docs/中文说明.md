# 中文说明

## 项目用途

本项目用车辆动力学模型和传感器融合估计车辆自身状态。车辆的横向速度、质心侧偏角和路面附着系数通常没有直接、低成本的测量方式，因此需要由 IMU、GNSS、轮速、转向角和模型共同推断。

## 代码对应关系

- `models/state.py`：定义状态字段、单位和输入检查；
- `models/vehicle.py`：动力学自行车模型；
- `models/tire.py`：有摩擦上限的 Fiala 侧向力；
- `filters/ekf.py`：扩展卡尔曼滤波器，使用 Joseph 形式更新协方差；
- `filters/ukf.py`：无迹卡尔曼滤波器；
- `simulation/sensors.py`：生成噪声、偏置、延迟和丢包；
- `experiments/runner.py`：固定随机种子的可复现实验。
- `simulation/vehicle_simulator.py`：生成真值、IMU、轮速和 GNSS 数据；
- `simulation/faults.py`：管理传感器 dropout、bias 和 delay 故障；
- `estimators/friction.py`：根据侧向力/法向载荷递推附着系数；
- `filters/imm.py`：对多个工况模型进行概率加权；
- `metrics/monte_carlo.py`：统计多次随机实验的均值、标准差和 P95。

## 状态与单位

`VehicleState` 的数组顺序为 `[vx, vy, yaw_rate, yaw, x, y, friction, timestamp]`。速度单位为 m/s，位置单位为 m，角度和角速度分别为 rad 与 rad/s，附着系数无量纲，时间单位为 s。

## 运行方式

先运行 `python examples/quickstart.py` 查看最小结果，再运行 `python experiments/run_experiment.py --seed 7 --steps 200` 生成完整曲线和指标。所有随机数由 seed 控制，便于复现实验。

## 解释结果

RMSE 越小表示状态误差越小；NIS/NEES 用于判断估计协方差是否合理。项目没有实车数据时，README 和图表必须明确标注为 simulation。

高级基准脚本会把单次曲线扩展为统计实验。报告 Monte Carlo 结果时，应同时说明 trial 数量、随机种子、噪声参数和工况，不能只挑选最好的单次运行。
