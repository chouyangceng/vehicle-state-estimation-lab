# 车辆状态估计实验室：中文说明

## 项目定位

本项目面向车辆工程本科生，使用低阶车辆动力学模型、轮胎模型和 IMU/GNSS/轮速观测，研究纵向速度、横向速度、横摆角速度、航向角和路面附着系数的状态估计。核心算法不依赖 ROS 2，便于在普通 Python 环境中复现实验。

## 目录与运行

- `models/`：车辆、轮胎和状态定义。
- `filters/`：EKF、UKF 和 IMM 滤波器。
- `simulation/`：可复现工况、传感器噪声、延迟、丢包和偏置。
- `metrics/`：RMSE、NIS、NEES、Gramian 和 CRLB 指标。
- `experiments/`：状态估计与可观测性实验入口。

```bash
python -m pip install -e .
python experiments/run_experiment.py --seed 7 --steps 200
python -m pytest -q
```

## 可观测性传感器消融实验

推荐从 `experiments/observability_study.py` 开始。程序在直线、正弦转向、双移线和低附着切换四类工况下，比较 IMU、轮速、GNSS 以及全传感器组合，并计算经验可观测 Gramian、有效秩、条件数、信息增益和 Cramér–Rao 下界。

```bash
python experiments/observability_study.py --fast --seed 7
```

输出目录 `artifacts/observability-study/` 包含：

- `results.json`：严格 JSON；不可观测 CRLB 方向用 `null` 和 `crlb_unbounded` 表示。
- `ranking.csv`：按信息质量排序的表格，可在 Excel 或 pandas 中继续分析。
- `observability.png`：无显示器环境也能生成的有效秩热图。
- `summary.md`：自动生成中文结论、复现设置、假设和局限。

详细的数学定义和字段说明见 [`observability_study.md`](observability_study.md)。配置文件为 `configs/observability.yaml`；CLI 内置同样的默认值，因此不安装 PyYAML 也能运行。

## ROS 2 接口

可选包位于 `ros2/vehicle_state_estimation_ros`，提供 `sensor_msgs/Imu`、`sensor_msgs/NavSatFix`、`sensor_msgs/JointState`、`nav_msgs/Odometry` 和诊断消息。安装 ROS 2 Humble/Iron 后可运行：

```bash
ros2 launch vehicle_state_estimation_ros estimator.launch.py
```

核心算法和可观测性实验不依赖 `rclpy`，没有 ROS 2 时原有测试仍可运行。

## 解释与局限

RMSE 越小表示估计误差越小，NIS/NEES 用于检查协方差一致性。经验 Gramian 是局部线性化指标，不等同于滤波器最终 RMSE；当前结果来自低阶自行车模型和理想观测，不能替代真实车辆试验。正式研究应报告工况、步长、噪声协方差和随机种子，并使用实车 CAN/IMU/GNSS 数据进行外部验证。
